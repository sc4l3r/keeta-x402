# Security Policy

## Supported Versions

Only the latest code available on the `main` branch is supported with security updates.
Security fixes are not guaranteed for previous releases, tags, branches, or forks at this point.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, report vulnerabilities using GitHub's [**Private Vulnerability Reporting** feature](https://github.com/sc4l3r/keeta-x402/security/advisories) privately to us.
We will then review reports and respond as quickly as possible, typically within a day.
